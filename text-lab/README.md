# Linux Text Processing Lab

This lab is used for a two-week intensive study of:

- grep
- regular expressions
- sed
- awk
- cut
- tr
- sort
- uniq
- paste
- join
- xargs
- jq
- Unix pipelines

## Directory map

00-basics       Basic text and pipeline exercises
01-grep         grep/search exercises
02-regex        Regular-expression exercises
03-cut-tr-sort  Column extraction and sorting
04-sed          Stream editing
05-awk          Field processing and aggregation
06-jq           JSON and NDJSON
07-security     SOC/security datasets
08-real-world   Nginx, Kubernetes, Docker, systemd
09-messy-data   Edge cases and malformed input

## Rule

Do not modify the original datasets during exercises.

If an exercise requires modification, create a copy first.

## Goal

Do not memorize commands.

Learn to:

1. Understand the input structure.
2. Choose the appropriate tool.
3. Build a pipeline.
4. Predict the output.
5. Explain why the command works.
6. Identify edge cases.
7. Produce an interview-quality solution.
